# Urdu Neural Translation using Transformer Models

## Overview
This project implements a neural machine translation system for Urdu text using deep learning.

The system is trained to translate sequences using transformer-based architectures.

---

## Structure
- training.ipynb → model training
- inference.ipynb → translation generation

---

## Technologies Used
- Python
- PyTorch
- NumPy

---

## Notes
This project demonstrates sequence-to-sequence learning and neural translation.
